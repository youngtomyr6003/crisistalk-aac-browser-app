## What is CrisisTalk AAC?

CrisisTalk AAC is a compact augmentative and alternative communication tool that opens directly in a browser. Its emergency-oriented layout brings symptoms, immediate needs, and rapid-response phrases together to help users share essential information in difficult or high-pressure circumstances.

The application supports people with speech impairments and situations requiring straightforward communication with emergency workers or first responders. It is distributed as a single HTML file, works without external dependencies or network access, offers eight languages, and can read selected messages aloud through the browser's Web Speech API.

---

## Core Capabilities

- Runs offline as one self-contained HTML file with no external dependencies
- Uses a responsive interface built with accessibility and WCAG support in mind
- Groups emergency phrases by symptoms, needs, and quick responses
- Provides an interactive body map and pain scale for communicating discomfort
- Supports communication in eight languages
- Offers text-to-speech through the browser Web Speech API
- Includes both light and dark visual themes
- Supports keyboard operation and screen readers
- Can provide optional click sounds through Web Audio
- Saves the chosen theme in browser local storage

## Using the Application

1. Open the HTML file in a supported browser.
2. Pick the language to use.
3. Select an emergency group, symptom, need, or quick-response message.
4. Describe physical discomfort with the body map or pain scale when appropriate.
5. Show the chosen message or activate text-to-speech if browser speech support is available.
6. Change between light and dark themes whenever necessary.

The controls can be operated with a keyboard, and screen reader support is available for users who do not rely solely on a mouse or other pointer.

## Preferences and Options

No separate configuration file is needed. CrisisTalk AAC manages its interface settings within the application, while the selected theme may be retained in the browser's local storage.

The available settings and browser-dependent options are:

- Light or dark appearance
- One of eight supported languages
- Text-to-speech through the Web Speech API when available
- Web Audio click feedback when supported by the browser and device

To remove the saved theme choice, clear the application's local browser storage or use the browser's storage-management settings.

### Is an internet connection needed?

No. After downloading, the single HTML file can be opened locally and used offline.

### Can CrisisTalk AAC read messages aloud?

Yes. When the browser exposes the Web Speech API and provides a compatible voice, selected messages can be spoken using text-to-speech.

### Which languages are included?

The application supports eight languages.

### How is the theme setting saved?

The light or dark theme choice is kept in the browser's local storage. Clearing the application's local storage removes that preference.

### What can I do if speech output is unavailable?

Check that the browser supports the Web Speech API, audio is enabled, and the device volume is raised. Speech support may differ according to the browser, operating system, and voices installed on the device.

### Does the app work with a keyboard?

Yes. CrisisTalk AAC includes keyboard navigation and screen reader support for accessible use.
